# Community code of conduct

Treat participants with respect. Welcome questions and constructive technical disagreement. Critique code and ideas with evidence; avoid personal attacks, harassment, discrimination, threats and sharing another person's private information.

This applies to issues, pull requests, reviews and other project spaces. Maintainers may edit or remove abusive material, restrict participation or close discussions to protect contributors. Decisions should be proportionate and explain the behavior involved.

Report concerns to the repository maintainer using an existing private contact channel. Reports should be handled privately, with attention to affected participants. Do not publish personal information or sensitive evidence in public discussions.
